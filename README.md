# Phishing Website / URL Detection Analysis

## 📌 Overview

This project focuses on analyzing phishing and legitimate URLs to identify patterns and characteristics associated with suspicious websites. The dataset is sourced from the PhiUSIIL Phishing URL Dataset available in the UCI Machine Learning Repository.

The dataset contains URL characteristics, domain information, HTTPS details, website content features, and a target label for analysis.

## 🎯 Objectives

- Understand the distribution of phishing and legitimate URLs.
- Identify and handle missing values.
- Detect duplicate records and examine data quality.
- Analyze URL length, domain characteristics, and special characters.
- Explore HTTPS usage and other website security-related features.
- Perform statistical analysis to identify patterns associated with phishing URLs.
- Visualize URL characteristics and relationships using graphs.
- Derive meaningful insights and recommendations from the analysis.

## 🛠️ Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📂 Dataset Information

- **Dataset Name:** PhiUSIIL Phishing URL Dataset
- **Original Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/967/phiusiil+phishing+url+dataset)
- **Original Dataset Size:** 235,795 rows and 55 columns
- **Target Column:** `label`

## 📊 Expected Outcome

To perform exploratory data analysis (EDA) on phishing and legitimate URLs, understand important URL and website characteristics, identify meaningful patterns through statistical analysis and visualizations, and provide insights that improve understanding of phishing-related website behavior.
